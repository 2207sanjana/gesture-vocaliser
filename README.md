# Gesture Vocaliser

An electronic glove that translates sign language gestures into spoken words using Arduino and Bluetooth.

## Overview
Designed to assist people with speech or hearing impairments by converting hand gestures into real-time audio output via a Bluetooth-connected device.

## Hardware used
- Arduino Uno
- Flex sensors (x5, one per finger)
- Bluetooth module (HC-05)
- Glove (base)
- Resistors, connecting wires

## How it works
1. Flex sensors on each finger detect the degree of bend
2. Analog readings are processed by the Arduino
3. Gesture patterns are matched to predefined sign language mappings
4. Output text is sent via Bluetooth to a terminal/app that vocalises it

## Technologies
`Arduino` `Embedded C` `IoT` `Bluetooth (HC-05)` `Sensor interfacing` `Signal processing`
